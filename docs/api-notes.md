# Roblox API & Protocol Hypotheses

This document records the hypotheses regarding Roblox endpoints, request headers, response formats, and URI protocols implemented in RbxManager. As specified in the Roblox Facts Policy, all items are verified with automated mock handlers and marked for real-world verification with throwaway accounts.

| Item | Endpoint / URI Pattern | Status | Notes |
| :--- | :--- | :--- | :--- |
| Cookie Validation | `GET https://users.roblox.com/v1/users/authenticated` | `VERIFIED-BY-TEST-ONLY` | Expects `.ROBLOSECURITY` cookie. Returns 200 with `{ "id": number, "name": string, "displayName": string }`. 401 indicates expired cookie. |
| Auth Ticket Generation | `POST https://auth.roblox.com/v1/authentication-ticket` | `VERIFIED-BY-TEST-ONLY` | Requires `.ROBLOSECURITY` cookie, `Referer: https://www.roblox.com/`, and `X-CSRF-TOKEN` (obtained via 403 challenge). Ticket returned in header `rbx-authentication-ticket`. |
| Launch Protocol URI | `roblox-player:1+launchmode:play+gameinfo:{ticket}+launchtime:{unixMs}+placelauncherurl:{encodedUrl}+browsertrackerid:{trackerId}+robloxLocale:en_us+gameLocale:en_us+channel:+LaunchExp:InApp` | `VERIFIED-BY-TEST-ONLY` | Formatted launch protocol registered under `HKCU\Software\Classes\roblox-player`. |
| Place Launcher URL | `https://assetgame.roblox.com/game/PlaceLauncher.ashx?request=RequestGame&browserTrackerId={trackerId}&placeId={placeId}&isPlayTogetherGame=false` | `VERIFIED-BY-TEST-ONLY` | URL-encoded and embedded into `placelauncherurl` in launch URI. |
| Specific Server Job URL | `https://assetgame.roblox.com/game/PlaceLauncher.ashx?request=RequestGameJob&browserTrackerId={trackerId}&placeId={placeId}&gameId={jobId}&isPlayTogetherGame=false` | `VERIFIED-BY-TEST-ONLY` | Variant for joining a specific game server instance by GUID. |
| Private Server Launch | `https://assetgame.roblox.com/game/PlaceLauncher.ashx?request=RequestGame&...&accessCode=...` | `UNVERIFIED` | Format could not be confirmed with high certainty from public docs. Feature marked BLOCKED in `STATE.md` and excluded from UI. |
| Public Server Browser | `GET https://games.roblox.com/v1/games/{placeId}/servers/Public?sortOrder=Asc|Desc&limit=100&cursor={cursor}` | `VERIFIED-LIVE` | Live verified on public place 1818. Unauthenticated GET (no cookie). Returns `{ "previousPageCursor": string?, "nextPageCursor": string?, "data": [ { "id": string, "maxPlayers": number, "playing": number, "fps": number?, "ping": number? } ] }`. Valid limit values: 10, 25, 50, 100. |
| Multi-Instance Singleton Objects | `ROBLOX_singletonMutex` / `ROBLOX_singletonEvent` | `UNVERIFIED-LIVE` | Public community sources only, Roblox may block. Created in manager process to permit multiple client instances without touching client memory or processes. |
