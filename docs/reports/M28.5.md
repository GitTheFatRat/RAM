# Milestone Report — M28.5: Strip WS_THICKFRAME and Use SWP_NOMOVE to Prevent Window Snap-Back on Drag

## Summary
- Updated `User32` (`src/Infrastructure/Native/User32.cs`) to:
  1. Import `GetWindowLongPtr` (`GetWindowLongPtrW`) and `SetWindowLongPtr` (`SetWindowLongPtrW`) from `user32.dll`.
  2. Strip `WS_THICKFRAME` (`0x00040000`) from `GWL_STYLE` (`-16`) before resizing so Windows and Roblox do not trigger `WM_GETMINMAXINFO` (`800x600`) minimum bounds enforcement when the user drags the window titlebar.
  3. Call `SetWindowPos` **once** after the window is initialized (`1500ms` post-`MainWindowHandle`) with `SWP_NOMOVE | SWP_NOZORDER | SWP_FRAMECHANGED | SWP_NOSENDCHANGING`, removing the background re-polling loop so window dragging is completely smooth and unobstructed.
