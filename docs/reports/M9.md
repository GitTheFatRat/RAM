# M9 Milestone Report: Code-Review Closure

## 1. Summary of Changes

1. **Repo Integrity**:
   - Removed `Backup*/` exclusion pattern from `.gitignore`.
   - Staged and tracked `src/Core/Backup/`, `src/Infrastructure/Backup/`, and `tests/Infrastructure.Tests/Backup/`.
   - Audited `git status --ignored --porcelain`: No needed source files are ignored. Ignored paths are strictly `bin/`, `obj/`, `logs/`, `artifacts/`, and `review.zip`.
   - Added `tools/verify-clean-clone.ps1` and quality guard `IgnoredSourceFilesTests`.
2. **Diagnostics & CSRF**:
   - Added domain record `AuthFailureDetails` in Core (`Stage`, `HttpStatus`, `RobloxErrorCodes`, `RobloxMessage`, `CsrfTokenObtained`, `ResponseHeaderNames`, `TicketHeaderPresent`) attached to failure `Result`.
   - Defensive JSON parsing in `RobloxAuthService.ParseRobloxErrorsAsync` (truncated to 120 chars, sanitized, never throws).
   - `RobloxCsrfHandler` sets `request.Options[CsrfTokenObtainedKey] = true` when 403 contains `x-csrf-token`, and replaced sync-over-async `GetAwaiter().GetResult()` with `await ReadAsByteArrayAsync`.
   - `DiagnosticsService` outputs all structured failure fields; removed bogus `CsrfValidationFailed` check.
   - Comprehensive unit tests covering 401, 403 w/ and w/o CSRF, 429, 500, 200 w/ missing ticket header, empty errors, and malformed JSON.
3. **Redaction Hardening**:
   - Removed all `FAKE_` literals from production code.
   - Redaction patterns updated to cover entire tokens: `_\|WARNING:-DO-NOT-SHARE-THIS\S*`, `\.ROBLOSECURITY=\S*`, and standalone secret tail `\|_[A-Za-z0-9]{16,}`.
   - Masked local Windows username in file paths (`C:\Users\<user>\...`).
   - `RobloxSecretRedactionEnricher` recursively sanitizes `StructureValue`, `SequenceValue`, and `DictionaryValue`.
   - Tests updated to realistic-shaped fake cookies.
4. **HTTP Hardening**:
   - Primary `SocketsHttpHandler` configured with `AllowAutoRedirect = false` and `UseCookies = false` via public factory `CreatePrimarySocketsHttpHandler()`.
   - `RobloxRetryHandler` disposes intermediate `HttpResponseMessage` before retry attempts via `OnRetry`.
5. **Cookie Memory Hygiene**:
   - `EncryptedFileVault` disposes loaded accounts' cookies in `finally` blocks in `AddAsync`, `UpdateAsync`, and `RemoveAsync`, preserving only caller-owned instances.
   - `RobloxLauncher` wraps accounts in `try ... finally` and disposes all cookies immediately after ticket acquisition.
   - Added unit test `CookieMemoryHygieneTests` asserting loaded cookies are disposed.
6. **Login Window Cleanup**:
   - Startup cleanup in `App.xaml.cs` removes leftover `%TEMP%\RbxManager\login-*` directories (best effort, logged).
   - WebView profile directory deletion retried up to 5 times (500ms delay).
   - 10-minute polling timeout terminates with `DialogResult = false` and localized message.
7. **No Hardcoded UI Language in Core/Infra**:
   - Replaced Vietnamese strings in `NamedMutexInstanceGate` and `DefaultInstanceGate` with error codes (`MultiInstanceNotAvailable`, `RobloxRunning`, `CouldNotTakeOver`, `Disposed`, `MutexError`, `Timeout`).
   - Mapped error codes to `Strings.resx` / `Strings.vi.resx` in `SettingsViewModel`.
   - Added quality guard `NoHardCodedVietnameseInCoreOrInfraTests`.
8. **Small Fixes**:
   - `EncryptedFileVault` writes temp files via `FileStream` and calls `Flush(true)`.
   - `NamedMutexInstanceGate._isEnabled` marked `volatile`; 5-second timeouts applied to command waits and disposal.
   - `ArchitectureTests` compares `Reveal()` allowlist by repo-relative paths (`src/Core/Models/SecretValue.cs`, `src/Infrastructure/Storage/EncryptedFileVault.cs`, `src/Infrastructure/Auth/RobloxAuthService.cs`, `src/Infrastructure/Launch/RobloxLauncher.cs`, `src/Infrastructure/Backup/EncryptedBackupService.cs`).
