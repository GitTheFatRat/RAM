## Implemented Scope
1. **Global Exception Handling**:
   - Registered `DispatcherUnhandledException`, `TaskScheduler.UnobservedTaskException`, and `AppDomain.UnhandledException` in `App.xaml.cs`.
   - Exceptions log only the exception type to prevent token/payload leaks. Localized UI dialogs prevent crash loops.
2. **App Single-Instance Protection**:
   - Added single-instance named mutex (`Local\RbxManager_Application_SingleInstance_Mutex`).
   - If already running, activates the existing window via Win32 `SetForegroundWindow` and exits cleanly.
3. **Graceful Application Teardown**:
   - `OnExit` stops all registered `IHostedService` instances (`SessionTracker`), disposes single-instance mutex, and flushes Serilog sinks.
4. **Log Redaction & Retention**:
   - Serilog rolling file sink retains logs for 14 days.
   - Implemented `RobloxSecretRedactionEnricher` masking `.ROBLOSECURITY=` and `_|WARNING:-DO-NOT-SHARE-THIS` as `[REDACTED]`.
5. **Keyboard Shortcuts**:
   - Implemented `Ctrl+F` (focus search box), `Delete` (delete selected account), and `Enter` (open launch dialog) in `AccountsPage`.
6. **Quality Guard Tests**:
   - `I18nParityTests`: 100% parity across `Strings.resx` and `Strings.vi.resx` with zero empty values.
   - `XamlLiteralTests`: Scans all `src/App.Wpf/**/*.xaml` and validates no raw text in `Text`, `Content`, `Header`, or `Title`.
   - `SecretScanTests`: Scans all tracked code and documentation outside tests, guaranteeing zero live secrets.
   - Dependency Audit: 0 vulnerabilities found.
7. **Packaging & CI**:
   - `tools/publish.ps1` produces framework-dependent single-file archive `artifacts/RbxManager-win-x64.zip` (supports `-SelfContained` flag).
   - `.github/workflows/build.yml` updated to build, test, package, and upload archive artifact.
8. **Documentation**:
   - `README.vi.md`: Comprehensive Vietnamese user guide.

   - `docs/BEFORE_PUBLIC_RELEASE.md`: Security, licensing, and code signing checklist.
