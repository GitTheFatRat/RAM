# M24 Report — C# WPF Application Protection & Obfuscation

## Protections Implemented
1. **Obfuscar Integration** (`Directory.Packages.props`, `src/App.Wpf/App.Wpf.csproj`, `src/App.Wpf/obfuscar.xml`)
   - Added `Obfuscar` (v2.2.50) and configured `obfuscar.xml` with string encryption (`HideStrings=true`), private/internal symbol renaming with Unicode name mangling (`HidePrivateApi=true`, `UseUnicodeNames=true`), method optimization (`OptimizeMethods=true`), and `SuppressIldasm=true` across `RbxManager.Core.dll`, `RbxManager.Infrastructure.dll`, and `RbxManager.App.dll`.
   - Preserved public ViewModel properties and View types (`KeepPublicApi=true` + explicit `SkipProperty`/`SkipType` rules) so WPF XAML bindings and JSON serialization remain intact.
   - Hooked `ObfuscateReleaseBuild` MSBuild target to run automatically before `ComputeFilesToPublish` / `PrepareForPublish` on RID-targeted Release builds without affecting `dotnet test`.
2. **Trimming, ReadyToRun, & Symbol Stripping** (`Directory.Build.props`, `src/App.Wpf/App.Wpf.csproj`)
   - Enabled `TrimMode=partial` with `_SuppressWpfTrimError=true`, `SuppressTrimAnalysisWarnings=true`, and `TrimmerRootAssembly` preservation so framework assemblies are trimmed safely without breaking WPF reflection.
   - Stripped all PDB debug symbols (`DebugType=none`, `DebugSymbols=false`) on Release builds.
