# M25.1 Report — JSON Serialization Source Generation for Trimmed Builds

## Root Cause
Publishing with `-p:PublishTrimmed=true` sets the .NET runtime feature switch `JsonSerializerIsReflectionEnabledByDefault=false`. Reflection-based `JsonSerializer.Serialize` / `Deserialize` calls threw `InvalidOperationException: Reflection-based serialization has been disabled for this application`.

## Changes
1. **Infrastructure Source-Generated Context** (`src/Infrastructure/Serialization/RbxManagerJsonContext.cs`)
   - Created `RbxManagerJsonContext : JsonSerializerContext` with `[JsonSerializable]` attributes for `AppSettings`, `AdvancedSettings`, `UiStateSettings`, `List<AccountDto>`, `AccountDto`, `List<EncryptedBackupService.BackupAccountDto>`, `EncryptedBackupService.BackupAccountDto`, `RobloxAuthService.AuthenticatedUserDto`, `ServerBrowserService.RobloxServerListResponse`, and `ServerBrowserService.RobloxServerItem`.
   - Updated `SettingsService`, `EncryptedFileVault`, `EncryptedBackupService`, `RobloxAuthService`, and `ServerBrowserService` to pass `JsonTypeInfo<T>` from `RbxManagerJsonContext.Default` / `RbxManagerJsonContext.Indented`.
2. **CDP Browser Launcher Source-Generated Context** (`src/App.Wpf/Services/IncognitoBrowserLauncher.cs`)
   - Replaced anonymous CDP parameter objects with typed records (`CdpScriptParams`, `CdpNavigateParams`, `CdpEvaluateParams`) and `CdpJsonContext : JsonSerializerContext`.
3. **Trim Analysis & Obfuscar Verification** (`Directory.Build.props`, `src/App.Wpf/obfuscar.xml`)
   - Removed `SuppressTrimAnalysisWarnings` so `TreatWarningsAsErrors=true` enforces zero `IL2026` reflection serialization warnings at build/publish time.
   - Excluded generated `*JsonContext*` and DTO properties in `obfuscar.xml`.
