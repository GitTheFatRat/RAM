# M25.5 Report — Persistent Place ID

## Changes
1. **`AppSettings`** (`src/Core/Settings/AppSettings.cs`)
   - Added `string? LastPlaceId = null` to `AppSettings` so the last-used Place ID is serialized into `settings.json`.
2. **`ServersViewModel`** (`src/App.Wpf/ViewModels/ServersViewModel.cs`)
   - Injected `ISettingsService` and populated `PlaceIdText` from `CurrentSettings.LastPlaceId` on startup when non-empty.
   - Added `OnPlaceIdTextChanged` partial handler so updating `PlaceIdText` persists `LastPlaceId` to `ISettingsService`.
3. **`AccountsViewModel` & `SettingsViewModel`** (`src/App.Wpf/ViewModels/AccountsViewModel.cs`, `src/App.Wpf/ViewModels/SettingsViewModel.cs`)
   - Synchronized `AccountsViewModel` launch dialogs (`_lastPlaceId`) with `LastPlaceId` in `ISettingsService` and preserved `LastPlaceId` + `UiState` when saving settings.
4. **Tests** (`tests/Core.Tests/Settings/AppSettingsTests.cs`, `tests/App.Wpf.Tests/Views/XamlSmokeTests.cs`)
   - Added `AppSettings_Clamp_PreservesLastPlaceId` and `ServersViewModel_PlaceIdText_LoadsFromAndSavesToSettingsService`.
