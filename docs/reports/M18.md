# M18 Milestone Report: Live Integration Test Suite (No Mocks)

## 1. Summary of Changes
- **Created Live Test Project (`tests/Infrastructure.LiveTests/`)**:
  - Target framework `net10.0-windows`, xUnit.
  - Zero fakes or mocks: instantiates and exercises real `RobloxHttpClientFactory`, `RobloxAuthService`, and `ServerBrowserService`.
- **Environment Guard & Default Test Isolation**:
  - Project excludes `[Trait("Category", "Live")]` from default `dotnet test` runs via `<VSTestTestCaseFilter Condition="'$(VSTestTestCaseFilter)' == ''">Category!=Live</VSTestTestCaseFilter>` so `verify-clean-clone.ps1` and CI runs are unaffected.
  - Each test checks `Environment.GetEnvironmentVariable("RBX_LIVE_TEST_COOKIE")` and exits immediately if unset.
- **Read-Only Live API Tests (`RobloxLiveIntegrationTests`)**:
  - `ValidateCookieAsync_WithRealCookie_ReturnsAuthenticatedRobloxUser`: Validates cookie against `https://users.roblox.com/v1/users/authenticated` and asserts `UserId > 0` and non-empty `Name`.
  - `GetServersAsync_WithBloxFruitsPlaceId_ReturnsLiveServersWithValidJobIdsAndCounts`: Queries `https://games.roblox.com/v1/games/2753915549/servers/Public` (Blox Fruits) and asserts non-empty server list, valid `JobId`s, and valid player counts.
- **Runner Script (`tools/run-live-tests.ps1`)**:
  - Accepts `-Cookie` parameter (or `RBX_LIVE_TEST_COOKIE` env var) and executes `tests/Infrastructure.LiveTests/Infrastructure.LiveTests.csproj` with `--filter Category=Live`.

## 2. Gate Results
- `dotnet build -c Release`: 0 warnings, 0 errors.
