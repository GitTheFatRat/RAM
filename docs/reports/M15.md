## 2. Scope & Implementation Details

### Section 1: Vault Format v2 & Master Password Safety
- **Cryptographic Header & AAD**:
  - Full 34-byte prefix (`RBXV` + version `0x02` + kdfType `0x01` + memoryKb `0x00010000` + iterations `0x00000003` + parallelism `0x00000004` + 16B salt) is authenticated via AES-256-GCM AAD. Any header bit-flip throws `VaultCorruptedException`.
  - For DPAPI-only format, 6-byte prefix (`RBXV\x02\x00`) is authenticated via AAD.
- **Minimum Parameter Enforcement**:
  - Enforced on vault load: memory >= 65536 KB (64 MiB), iterations >= 3, parallelism >= 1. Parameters below safe thresholds trigger immediate corruption rejection.
- **Automatic Migration Backup**:
  - Prior to writing Format v2 over a Format v1 vault, `vault.dat` is safely copied to `vault.dat.v1.bak`. If that backup already exists, a timestamped copy (`vault.dat.v1.yyyyMMddHHmmssfff.bak`) is created.
- **Irreversible Risk Acknowledgment**:
  - Setup control requires explicit user acknowledgment via `AcknowledgeIrreversibleCheckBox` before enabling master password protection.

### Section 2: Proxy Scope & Credential Hygiene
- Configured proxies apply strictly to application HTTP requests and WebView2 login.
- Documented in `SECURITY.md` that game client UDP traffic connects directly to game servers.
- Proxy passwords stored exclusively in encrypted vault (`SecretValue`), decrypted only during basic auth challenge in memory.

### Section 3: Risky Window & Process Features
- **Window Controller (`WindowController.cs`)**:
  - Abstracted native calls behind `INativeWindowMethods` interface.
  - Operates strictly on tracked PIDs (`SessionTracker.ActiveSessions`), skips foreground window PID, minimizes without activation (`SW_SHOWMINNOACTIVE = 7`).
  - Completely removed `SetWindowPos` off-screen repositioning and synthetic inputs.
- **Memory Optimizer (`WindowsMemoryOptimizer.cs`)**:
  - Abstracted native calls behind `INativeProcessMemoryMethods`.
  - Minimal privileges: requests `PROCESS_SET_QUOTA = 0x0100` only.
  - Skips foreground window PID; records accurate counts of trimmed, access-denied, and failed processes.
- **RAM Cleaner Service (`RamCleanerService.cs`)**:
  - Injects `ISessionTracker` to target only tracked Roblox PIDs.
  - Automatically disables the feature after 3 consecutive access-denied cycles.
- **Risk Acknowledgments**:
  - Added localized confirmation dialogs in `SettingsViewModel.cs` for Background Throttler and RAM Cleaner.

### Section 4: Ghost Disconnect Safeguards
- **GhostDisconnectMode**:
  - Tri-state enum (`Off`, `NotifyOnly`, `KillAndRejoin`). Default is `NotifyOnly`.
- **Keyword Validation (`GhostDisconnectKeywordValidator.cs`)**:
  - Enforces max 20 keywords, 3–80 characters. Removed bare "DisconnectReason".
- **Unambiguous Log Mapping (`RobloxLogWatcher.cs`)**:
  - Binds only if exactly 1 unassigned log file was created within 20s of process start. If ambiguous (2+ files), logs warning with counts only and skips monitoring.
- **Kill Safeguards (`SessionTracker.cs`)**:
  - Process kill permitted ONLY when mode is `KillAndRejoin`, session age >= 60 seconds, and outside 5-minute cooldown.

### Section 5: Launch Precheck & Registry Safety
- Removed registry check as a blocking gate in `RobloxLauncher.cs`.
- Catches `Win32Exception` (codes 1155 and 2) and maps them cleanly to `RobloxNotInstalledOrRegistered`.
- Moved registry inspection into `DiagnosticsService.cs` as non-blocking diagnostic probes across HKCU, HKLM, HKCR with username redaction.

### Section 6: UI Defects Fixed

- Added and wired empty/error state hints in both `Strings.resx` and `Strings.vi.resx`.

- Fixed `AccountsPage` SearchBox height and vertical alignment.
- Set `Foreground="{DynamicResource TextFillColorPrimaryBrush}"` on all page headers for consistent contrast.
