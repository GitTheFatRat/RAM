# M14.3 Report: Deep UI/UX Polish & DataGrid Restyling

**Target**: Post-M14 Hotfix  
**Date**: 2026-10-22  
**Status**: All Gates Passed

## 1. Scope & Implementation Summary

### Problem
1. **White DataGrid Rows in Dark Mode**: Standard WPF `DataGridRow` defaults `Background` to `SystemColors.WindowBrush` (#FFFFFF in default Windows themes). Because page-level row styles previously overrode or failed to explicitly set dark dynamic resource backgrounds on `DataGridRow`, rows rendered as glaring white blocks.
2. **Elevation & Visual Contrast**: Main content areas lacked elevation and visual separation from the main application window background.
3. **Column Header Legibility**: Default column headers lacked bold typography, uppercase styling, and distinct divider lines.

### Solution
- **`src/App.Wpf/Themes/Tokens.xaml`**:
  - Added theme tokens: `DividerStrokeColorDefaultBrush` (Dark: `#383838`, Light: `#E0E0E0`), `ControlFillColorSecondaryBrush` (Dark: `#363636`, Light: `#E8E8E8`), and `ControlFillColorTertiaryBrush` (Dark: `#444444`, Light: `#DCDCDC`).
  - Added `HighContrastColumnHeaderStyle` targeting `DataGridColumnHeader` with `FontWeight="Bold"`, `Typography.Capitals="AllSmallCaps"`, `BorderThickness="0,0,0,1"`, `BorderBrush="{DynamicResource DividerStrokeColorDefaultBrush}"`, and `Background="{DynamicResource CardBackgroundBrush}"`.
  - Added `HighContrastDataGridRowStyle` setting `Background="{DynamicResource ControlFillColorDefaultBrush}"`, `Foreground="{DynamicResource TextFillColorPrimaryBrush}"`, `BorderThickness="0"`, with `ItemsControl.AlternationIndex == 1` trigger for `ControlFillColorSecondaryBrush`, `IsMouseOver` trigger for `ControlFillColorTertiaryBrush`, and `IsSelected` trigger.
  - Added `HighContrastDataGridCellStyle` ensuring `Foreground="{DynamicResource TextFillColorPrimaryBrush}"` and transparent background on selection so row background is seamlessly respected.
- **`src/App.Wpf/Themes/ThemeTokens.cs`**:
  - Registered `ControlFillColorSecondaryBrush`, `ControlFillColorTertiaryBrush`, and `DividerStrokeColorDefaultBrush` in `ApplyTheme()`.
- **`src/App.Wpf/MainWindow.xaml`**:
  - Forced explicit background on the root `Grid`: `Background="{DynamicResource ApplicationBackgroundBrush}"`.
- **Pages (`AccountsPage.xaml`, `RunningPage.xaml`, `ServersPage.xaml`)**:
  - Wrapped DataGrid content areas inside elevated `<Border>` containers featuring `Background="{DynamicResource CardBackgroundBrush}"`, `BorderBrush="{DynamicResource DividerStrokeColorDefaultBrush}"`, `BorderThickness="1"`, `CornerRadius="{StaticResource RadiusMedium}"`, and `Margin="{StaticResource MarginBase}"`.
  - Applied `Background="{DynamicResource CardBackgroundBrush}"`, `RowBackground="{DynamicResource ControlFillColorDefaultBrush}"`, `AlternatingRowBackground="{DynamicResource ControlFillColorSecondaryBrush}"`, `AlternationCount="2"`, and `Foreground="{DynamicResource TextFillColorPrimaryBrush}"` to DataGrids.
  - Linked `ColumnHeaderStyle="{StaticResource HighContrastColumnHeaderStyle}"`, `RowStyle="{StaticResource HighContrastDataGridRowStyle}"`, and `CellStyle="{StaticResource HighContrastDataGridCellStyle}"`.
