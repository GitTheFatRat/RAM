## 1. Scope & Implementation Summary

### Core
- **Settings**:
  - `AppSettings` gains: `bool EnableGhostDisconnectDetection` (default: `true`).
  - Clamping preserves value.
- **Contracts**:
  - `IRobloxLogWatcher`: Interface defining `StartWatching(int pid, DateTimeOffset startTime, string? explicitLogPath = null)`, `StopWatching(int pid)`, and event `event Action<int, string>? GhostDisconnectDetected`.

### Infrastructure
- **`RobloxLogWatcher` (`IRobloxLogWatcher`)**:
  - Resolves active session log files located in `%LOCALAPPDATA%\Roblox\logs` by matching creation timestamp against session start time (fallback to latest modified `*Player*.log`).
  - Tails log files using a non-blocking `FileStream` configured with `FileShare.ReadWrite | FileShare.Delete` and `StreamReader`.
  - Scans for disconnection keywords:
    - `"Connection lost"`
    - `"DisconnectReason"`
    - `"Error 277"`
    - `"Error 268"`
  - Emits `GhostDisconnectDetected(pid, keyword)` and stops tailing upon first match.
  - Releases file handles and locks immediately when `StopWatching(pid)` or `Dispose()` is invoked.
  - Security adherence: Strictly reads disk log files; zero process memory inspection, injection, or handle duplication.
- **`SessionTracker`**:
  - Injected `IRobloxLogWatcher`.
  - When a session is bound or registered to a PID, automatically calls `_logWatcher.StartWatching(pid, startTime)`.
  - Listens to `GhostDisconnectDetected`:
    - Checks `AppSettings.EnableGhostDisconnectDetection`.
    - If enabled and PID is active, logs the event and terminates the frozen process via `_processProvider.Kill(pid, graceful: false)`.
    - Process termination naturally triggers the standard `SessionEnded` and `HandleAutoRejoinAsync` lifecycle.
  - Cleans up log tailing via `_logWatcher.StopWatching(pid)` upon session termination.

### App.Wpf
- **Settings View & ViewModel**:
  - Added observable property `EnableGhostDisconnectDetection` to `SettingsViewModel`.
  - Added `ui:ToggleSwitch` for "Enable Ghost Disconnect Detection (Read Logs)" in `SettingsPage.xaml` under the Auto-rejoin card.
  - Added full localization parity in `Strings.resx` and `Strings.vi.resx`:
    - `EnableGhostDisconnectDetection`
    - `EnableGhostDisconnectDetectionDescription`
