## 1. Scope & Implementation Summary

### Core
- **Settings**:
  - `AppSettings` gains:
    - `bool EnableRamCleaner` (default: `false`).
    - `int RamCleanerIntervalMinutes` (default: `15`, min: `5`, max: `120`).
  - `AppSettings.Clamp()` updated to enforce bounds:
    - `Math.Clamp(RamCleanerIntervalMinutes, MinimumRamCleanerIntervalMinutes, MaximumRamCleanerIntervalMinutes)`.
- **Contracts**:
  - `IMemoryOptimizer`: new interface with a single method `Task TrimMemoryAsync(CancellationToken ct = default)`.

### Infrastructure
- **`WindowsMemoryOptimizer` (`IMemoryOptimizer`)**:
  - P/Invoke Win32 API `kernel32.dll`:
    - `SetProcessWorkingSetSize(IntPtr hProcess, int dwMinimumWorkingSetSize, int dwMaximumWorkingSetSize)`.
    - `OpenProcess(uint dwDesiredAccess, bool bInheritHandle, int dwProcessId)`.
  - Process handle management:
    - Opens tracked Roblox processes with `PROCESS_SET_QUOTA` (0x0100) and `PROCESS_QUERY_INFORMATION` (0x0400).
    - Wraps handles inside `SafeProcessHandle` for automatic resource cleanup.
    - Passes `-1` for both minimum and maximum sizes, triggering the Windows kernel working set trimmer to swap out idle and unreferenced pages.
    - Gracefully catches and ignores `ERROR_ACCESS_DENIED` and `ERROR_INVALID_PARAMETER` for elevated or terminating processes.
    - Logs operation counts only (e.g. `trimmed X of Y Roblox processes`) to strictly enforce security guidelines.
- **`RamCleanerService` (`BackgroundService`)**:
  - Hosted worker evaluating `AppSettings.EnableRamCleaner`.
  - When enabled: waits for `RamCleanerIntervalMinutes`, invokes `IMemoryOptimizer.TrimMemoryAsync()`, and logs cycle operation counts.
  - When disabled: sleeps on a responsive idle cycle to detect settings changes immediately.
  - Cleanly handles `OperationCanceledException` upon cancellation / shutdown.
- **Dependency Injection**:
  - Registered `IMemoryOptimizer` -> `WindowsMemoryOptimizer` as Singleton.
  - Registered `RamCleanerService` as Hosted Service.

### App.Wpf
- **Settings View & ViewModel**:
  - Added observable properties: `EnableRamCleaner` and `RamCleanerIntervalMinutes`.
  - Dynamic formatted display: `RamCleanerIntervalDisplay` using cached `CompositeFormat` (`{0} min` / `{0} phút`).
  - Added `ui:ToggleSwitch` for "Enable Smart RAM Cleaner" and WPF `Slider` (range 5 to 120, tick 5) under "Performance & Optimization".
  - Slider is automatically disabled when the toggle is off.
- **Localization**:
  - Full parity in `Strings.resx` and `Strings.vi.resx`:
    - `EnableRamCleaner`, `EnableRamCleanerDescription`, `RamCleanerInterval`, `RamCleanerIntervalDescription`, `RamCleanerIntervalFormat`.
  - Verified by `I18nParityTests` and `LocalizationAuditTests`.
