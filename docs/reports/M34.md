# M34 FEATURE: Account Rotation Scheduler & Deep Cache Cleaner

## PROBLEM
1. The user needs to farm 50-100 accounts daily, but the hardware limit is 15-20 simultaneous instances. Manual switching every few hours is tedious.
2. Continuous 24/7 farming generates massive amounts of temporary data (crash dumps, HTTP caches, text logs) in `%localappdata%\Roblox`, which causes Disk I/O bottlenecks and slows down future instance launches.

## TASKS

1. **Deep Cache Auto-Cleaner (`RobloxCacheCleanerService`):**
   - Identify target directories: 
     - `%localappdata%\Roblox\logs` (Target `.log` and `.dmp` files).
     - `%localappdata%\Roblox\http` (HTTP cache).
     - `%temp%\Roblox`
   - Implement a deletion logic that uses `try-catch` to silently ignore `IOException` (since running Roblox instances will lock their active log files).
   - Add a Settings UI toggle: "Tự động dọn rác trước khi mở (Auto-clean cache)".

2. **Account Rotation Scheduler (`RotationManager`):**
   - Add a UI section in the "Đang chạy" (Running) or "Tài khoản" (Accounts) tab for "Cấu hình xoay tua (Rotation)".
   - Allow users to select multiple existing Account Groups (e.g., Group 1, Group 2) and set a duration (e.g., X hours / Y minutes).
   - **Execution Loop:**
     1. Launch all accounts in Group 1.
     2. Wait for the specified duration (using a non-blocking `Task.Delay` or timer).
     3. Signal `SessionTracker` to aggressively kill all current managed sessions.
     4. Wait 10 seconds for processes to fully exit.
     5. Invoke `RobloxCacheCleanerService` to wipe the disk cache.
     6. Launch Group 2, and repeat the cycle.
