# Milestone Report: M21 — GoodbyeDPI Automation Orchestrator

## 1. Summary of Changes
- **Core Contract (`IDpiToolService`, `DpiErrorCodes`)**:
  - Created `src/Core/Network/IDpiToolService.cs` with `IsRunning()`, `EnsureInstalledAndStartAsync(CancellationToken)`, and typed error codes (`UacDenied`, `DownloadFailed`, `LaunchFailed`).
- **Orchestrator Service (`DpiToolService`)**:
  - Created `src/Infrastructure/Network/DpiToolService.cs`.
  - Checks if `goodbyedpi` is running via `IProcessProvider.IsProcessRunning("goodbyedpi")` or `Process.GetProcessesByName("goodbyedpi")`.
  - If `1_russia_blacklist.cmd` is not present in `%LOCALAPPDATA%\RbxManager\Tools\GoodbyeDPI`, downloads `https://github.com/ValdikSS/GoodbyeDPI/releases/download/0.2.3/goodbyedpi-0.2.3.zip` and extracts it to the Tools folder.
  - Launches `1_russia_blacklist.cmd` externally using `ProcessStartInfo` with `UseShellExecute = true` and `Verb = "runas"` for standard UAC Administrator elevation.
  - Maps `Win32Exception(1223)` (UAC prompt canceled) to `DpiErrorCodes.UacDenied` and HTTP/network errors to `DpiErrorCodes.DownloadFailed`.
- **UI & UX Polish (`AddAccountWindow.xaml`, `AddAccountViewModel.cs`, `AccountsViewModel.cs`)**:
  - Upgraded the top card in `AddAccountWindow.xaml` into a dynamic GoodbyeDPI status & orchestrator panel with an indeterminate `ProgressBar` (`IsStartingGoodbyeDpi`) and prominent button (`AutomationId="AddAccount_GoodbyeDpiButton"`).
  - Bound button content to `GoodbyeDpiButtonText` (`"Cài đặt & Bật GoodbyeDPI"` when stopped, `"✅ GoodbyeDPI đang hoạt động"` when running) and disabled state to `CanStartGoodbyeDpi`.
  - Displays localized error Snackbar and inline error message if UAC is denied or GitHub download fails.
