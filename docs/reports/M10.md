## 1. Scope & Implementation Summary

### Core
- **Proxy Configuration**:
  - `ProxyType` enum (`Http`, `Socks5`).
  - `ProxyConfig` record (`Host`, `Port`, `Username`, `SecretValue? Password`, `ProxyType Type`, `IDisposable`).
  - `ProxyConfigValidator`: strictly validates hostname/IP format (preventing invalid IP formats like `999.999.999.999`), ensures protocol schemes are omitted, and validates port range (1–65535).
- **Domain Models & Validation**:
  - `Account` record updated with `ProxyConfig? Proxy = null`.
  - `AccountValidator` validates `ProxyConfig` when present.
- **Master Password Policy & Vault Key Provider**:
  - `MasterPasswordPolicy`: enforces minimum 12-character master passwords.
  - `IVaultKeyProvider`: interface for supplying and storing the master password in-memory.

### Infrastructure
- **Vault Storage Format v2**:
  - Upgraded `EncryptedFileVault` to Format v2 (`version = 0x02`).
  - Binary layout: `magic` ("RBXV" 4B) | `version` (0x02 1B) | `kdfType` (1B: 0x00=DPAPI only, 0x01=Argon2id+DPAPI) | [if kdfType 0x01: `argonSalt` 16B] | `wrappedKeyLength` (UInt16 LE) | `wrappedKey` | `nonce` (12B) | `tag` (16B) | `ciphertext`.
  - AAD: 22 bytes for Argon2id (`RBXV\x02\x01` + 16B salt), 6 bytes for DPAPI only (`RBXV\x02\x00`).
  - Double-layer protection: The derived Argon2id key is additionally wrapped with Windows DPAPI (`DataProtectionScope.CurrentUser`). Decryption requires both the correct master password and execution under the valid Windows user account.
  - Backward compatibility: Transparent fallback loads Format v1 (`version = 0x01`) vaults and automatically upgrades them to Format v2 on subsequent saves.
- **Argon2id Package & Parameters**:
  - Package: `Konscious.Security.Cryptography.Argon2` version `1.3.1` (net10.0 compatible).
  - Memory size: 65,536 KB (64 MB).
  - Iterations: 3.
  - Degree of parallelism: 4 lanes / threads.
  - Salt: 16 cryptographically secure random bytes.
  - Output key length: 32 bytes (256-bit AES-GCM data key).
- **Per-Account Proxy Routing**:
  - `RobloxHttpClientFactory` & `IRobloxHttpClientFactory`: constructs `HttpClient` with `SocketsHttpHandler` and `WebProxy` configured for `http://` or `socks5://` schemes and `NetworkCredential`.
  - `RobloxAuthService`: accepts `IRobloxHttpClientFactory` and routes cookie validation and authentication ticket retrieval through the account's configured proxy.
  - Reveal allowlist update: Added `src/Infrastructure/Http/RobloxHttpClientFactory.cs` to `AllowedRevealRelativePaths` in `ArchitectureTests.cs`.
    - *Justification*: Decrypting `ProxyConfig.Password` into `NetworkCredential` for `WebProxy` authentication.
- **Background Resource Optimization**:
  - `WindowController`: Win32 P/Invoke (`user32.dll`: `EnumWindows`, `GetWindowThreadProcessId`, `GetForegroundWindow`, `ShowWindow`, `SetWindowPos`, `IsWindowVisible`) to minimize non-foreground `RobloxPlayerBeta` client windows with `SW_SHOWMINNOACTIVE` (7).
  - `BackgroundWindowThrottler`: `BackgroundService` hosted worker running a 3-second evaluation loop to throttle or restore Roblox instances when toggled in settings.

### App.Wpf
- **Master Password Startup Flow**:
  - Blocking localized `MasterPasswordWindow` shown prior to `MainWindow` if `IsMasterPasswordEnabled == true`.
  - Typed `VaultCorruptedException` / `CryptographicException` caught with inline error display without wiping the vault or crashing.
- **Settings Page**:
  - Added "Security" card with "Enable Master Password" toggle. Prompts with `MasterPasswordSetupControl` (enters password twice, validates >= 12 chars), sets key in `IVaultKeyProvider`, re-encrypts vault with Format v2 `kdfType = 0x01`.
  - Disabling prompts for confirmation, clears the key, and re-encrypts vault with Format v2 `kdfType = 0x00`.
  - Added "Performance & Optimization" card with "Throttle background Roblox instances" toggle.
- **Account Editor**:
  - Added TabControl to `AccountEditorControl`: "General" tab and "Proxy" tab.
  - Fields: Proxy Type (ComboBox: HTTP, SOCKS5), Host, Port, Username, Password (PasswordBox).
  - Clean password memory hygiene: read on save, cleared immediately.
- **Localization**:
  - All user-facing strings added to `Strings.resx` and `Strings.vi.resx` with zero hardcoding.
