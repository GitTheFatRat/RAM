# M14.1 Report: Hotfix for Illegal Binding on ConverterParameter in ServersPage

**Target**: Post-M14 Hotfix  
**Date**: 2026-10-22  
**Status**: All Gates Passed

---

## 1. Scope & Implementation Summary

### Problem
- In `src/App.Wpf/Views/Pages/ServersPage.xaml`, line 99 declared:
  ```xml
  <DataGridTextColumn Header="{x:Static res:Strings.ColumnPlayers}"
                      Binding="{Binding StringFormat='{}{0}/{1}', Path=Playing, ConverterParameter={Binding MaxPlayers}}"
                      Width="120" />
  ```
- Because `ConverterParameter` on `Binding` is a CLR property (not a `DependencyProperty` on a `DependencyObject`), WPF throws a runtime `System.Windows.Markup.XamlParseException` upon opening `ServersPage`.

### Fix
- Replaced the illegal `DataGridTextColumn` with a `DataGridTemplateColumn`:
  ```xml
  <DataGridTemplateColumn Header="{x:Static res:Strings.ColumnPlayers}"
                          SortMemberPath="Playing"
                          Width="120">
      <DataGridTemplateColumn.CellTemplate>
          <DataTemplate>
              <TextBlock VerticalAlignment="Center">
                  <TextBlock.Text>
                      <MultiBinding StringFormat="{}{0}/{1}">
                          <Binding Path="Playing" />
                          <Binding Path="MaxPlayers" />
                      </MultiBinding>
                  </TextBlock.Text>
              </TextBlock>
          </DataTemplate>
      </DataGridTemplateColumn.CellTemplate>
  </DataGridTemplateColumn>
  ```
- `SortMemberPath="Playing"` preserves player count sorting when clicking the column header.
- Added a permanent quality guard test in `tests/Infrastructure.Tests/QualityGuards/XamlScanTests.cs` (`NoBindingOnConverterParameter_InAnyXamlFile`) that scans all `.xaml` files across the repository to ensure no binding is assigned to `ConverterParameter`.
