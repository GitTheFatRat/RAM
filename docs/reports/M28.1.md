# Milestone Report — M28.1: Custom Resolution Settings Persistence

## Summary
- Updated `SettingsViewModel` (`src/App.Wpf/ViewModels/SettingsViewModel.cs`) so `EnableCustomResolution`, `ResolutionWidth`, and `ResolutionHeight` are loaded strictly from `ISettingsService.CurrentSettings` (with an `_isLoadingSettings` guard) and automatically persisted via `SaveSettingsAsync` inside `OnEnableCustomResolutionChanged`, `OnResolutionWidthChanged`, and `OnResolutionHeightChanged` whenever their values change.
- Updated `SettingsPage.xaml` (`src/App.Wpf/Views/Pages/SettingsPage.xaml`) to bind `ResolutionWidth` and `ResolutionHeight` to `TextBox` controls with `Mode=TwoWay, UpdateSourceTrigger=PropertyChanged` and `EnableCustomResolution` with `Mode=TwoWay`, and refreshed `LoadFromCurrentSettings()` on `SettingsPage.Loaded` (`src/App.Wpf/Views/Pages/SettingsPage.xaml.cs`).
- Lowered `AppSettings.MinimumResolutionDimension` to `64` (`src/Core/Settings/AppSettings.cs`) so custom compact resolutions like `200x400` persist without premature clamping during typing.
