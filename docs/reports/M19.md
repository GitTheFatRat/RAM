# Milestone Report: M19 — UAT Live Trace & Diagnostic Telemetry

## 1. Summary of Changes
- **Settings & Toggle (`AppSettings`, `SettingsViewModel`, `SettingsPage.xaml`)**:
  - Added `bool EnableUatTelemetry = false` to `AppSettings`.
  - Added localized toggle `"Bật chế độ ghi log thực chiến ra Desktop"` (`EnableUatTelemetry`) in the **Advanced** card of `SettingsPage.xaml` (`AutomationId="Settings_UatTelemetryToggle"`), wired to `EnableUatTelemetryToggledCommand` in `SettingsViewModel`.
- **UAT Trace Logger (`IUatLogger`, `UatLogger`)**:
  - Implemented `UatLogger` in `src/Infrastructure/Logging/UatLogger.cs` writing UTF-8 timestamped trace entries to `Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.Desktop), "RbxManager_UAT_Trace.txt")` only when `EnableUatTelemetry` is `true`.
  - Enforced automatic regex masking (`UatLogger.MaskSecrets`) replacing `.ROBLOSECURITY` cookies and `gameinfo:` launch tickets with `***`.
- **Interception Points**:
  1. **Launcher (`WindowsProcessStarter.Start`)**: Logs the exact `Process.Start` URI with `gameinfo:***` masked and `UseShellExecute` flag.
  2. **Win32 P/Invoke (`WindowController` & `WindowsMemoryOptimizer`)**: Logs `ShowWindow` signals and `Calling SetProcessWorkingSetSize(-1, -1) on PID {pid}`.
  3. **Session Tracker (`SessionTracker`)**: Logs session binding (`Account`, `PID`, `PlaceId`, `JobId`), process exit, auto-rejoin scheduling/circuit-breaker states, smart server hop selections, and `RobloxLogWatcher` ghost disconnect triggers.
