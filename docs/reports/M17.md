# M17 Milestone Report: Remove Proxy Support & Implement Launch Pacing

## 1. Summary of Changes
- **Proxy Removal**:
  - Eliminated proxy configuration, models (`ProxyConfig`, `ProxyType`), validation (`ProxyConfigValidator`), process builders (`ProxyBrowserArgumentBuilder`), basic auth decisions (`ProxyAuthenticationDecision`, `IBasicAuthenticationChallenge`), and handlers (`WebViewProxyAuthHandler`).
  - Removed proxy parameters from `IRobloxAuthService`, `RobloxAuthService`, `IRobloxHttpClientFactory`, `RobloxHttpClientFactory`, `Account`, `AccountDto`, `EncryptedFileVault`, and ViewModels/Views (`AccountEditorViewModel`, `AccountEditorControl`, `LoginWindow`).
  - Primary HTTP handler delegates to Windows system proxy by default.
  - Diagnostics retains `SystemProxyInUse: yes/no` via `WebRequest.DefaultWebProxy`.
  - Vault payload backward-compatibility verified: legacy proxy fields in existing encrypted vaults are safely ignored on load and permanently purged on next save.
- **Launch Pacing & Single Gate**:
  - Replaced `LaunchDelayMs` with `LaunchDelaySeconds` (default: 20 seconds; range: 1 to 600 seconds) in `AppSettings`.
  - Added migration logic in `AppSettings.MigrateLegacyLaunchDelay(int legacyMs)` (legacy default 3000 ms migrates to 20 s; custom values rounded up and clamped).
  - Implemented unified launch pacing in `RobloxLauncher` protected by `SemaphoreSlim(1, 1)` and `TimeProvider`.
  - First launch is immediate without artificial delay; subsequent launches enforce `LaunchDelaySeconds` spacing.
  - Cancellation during wait aborts without consuming the interval.
  - Bound all 5 launch paths (single, bulk, server browser join, auto-rejoin, smart server hop) through the same gate.
  - Bulk launch in `AccountsViewModel` displays countdown ("Next account in Xs" / "Tài khoản tiếp theo sau Xs") with immediate queue cancellation button.
- **Sequential Cookie Validation**:
  - "Check all" executes sequentially with a fixed 2-second delay between accounts, preventing HTTP 429 rate limit spikes.
- **Reveal() Allowlist**:
  - Restricted strictly to the 5 permitted files in `ArchitectureTests`:
    1. `src/Infrastructure/Storage/EncryptedFileVault.cs`
    2. `src/Infrastructure/Storage/EncryptedBackupService.cs`
    3. `src/Infrastructure/Auth/RobloxAuthService.cs`
    4. `src/Infrastructure/Launch/RobloxLauncher.cs`
    5. `src/App.Wpf/ViewModels/AccountEditorViewModel.cs`
