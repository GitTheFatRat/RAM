# Milestone Report — M28: Force Custom Window Resolution via Win32 API

## Summary
- Added `EnableCustomResolution` (`false`), `ResolutionWidth` (`800`), and `ResolutionHeight` (`600`) to `AppSettings` (`src/Core/Settings/AppSettings.cs`) with dimension clamping (`200`–`7680` px).
- Implemented `User32` (`src/Infrastructure/Native/User32.cs`) with P/Invoke `SetWindowPos`, `SWP_NOMOVE = 0x0002`, `SWP_NOZORDER = 0x0004`, and `ResizeProcessMainWindowAsync` polling `Process.MainWindowHandle` every 500ms (up to 10s) and resizing the window without moving or reordering it.
- Hooked `User32.ResizeProcessMainWindowAsync` into `AccountsViewModel.OnRobloxProcessCapturedAsync` (`src/App.Wpf/ViewModels/AccountsViewModel.cs`) and `ServersViewModel.JoinServerAsync` (`src/App.Wpf/ViewModels/ServersViewModel.cs`) right after the spawned `RobloxPlayerBeta` Process ID is captured.
- Added UI toggle and Width/Height `NumberBox` inputs to `SettingsPage.xaml` (`src/App.Wpf/Views/Pages/SettingsPage.xaml`) and `SettingsViewModel` (`src/App.Wpf/ViewModels/SettingsViewModel.cs`) with full English/Vietnamese localization (`Strings.cs`, `Strings.resx`, `Strings.vi.resx`).
