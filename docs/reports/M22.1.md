# M22.1 Report — Randomized Sequential Launch (Anti-Bot Bypass)

## Summary
Implemented an asynchronous sequential multi-account launch queue with a randomized 60–120 second delay between each account to prevent anti-bot detection and simultaneous hardware spikes.

## Key Changes
1. **Sequential Top-to-Bottom Launch Queue & Randomized Delay (`src/App.Wpf/ViewModels/AccountsViewModel.cs`)**:
   - Updated `LaunchSelectedAccountsAsync` and `LaunchGroupAccountsAsync` to iterate through `FilteredAccounts` in strict top-to-bottom UI `DataGrid` order.
   - Extracted `ExecuteSequentialLaunchQueueAsync(IReadOnlyList<AccountItemViewModel> accounts, long placeId, string? jobId = null)` using a `foreach` loop that launches each account and, for every account except the last one in the queue, generates `int randomSeconds = _randomDelayGenerator(MinSequentialLaunchDelaySeconds, MaxSequentialLaunchDelaySeconds + 1)` (`60..120` inclusive) and awaits `Task.Delay(TimeSpan.FromSeconds(randomSeconds))`.
   - Added `CanLaunchAccount => IsAccountSelected && !IsBulkLaunching` with property-change notifications on `SelectedAccount` and `IsBulkLaunching` so single-account and multi-account launch actions cannot be spam-clicked while a launch sequence is running.
2. **Server Join Multi-Account Sequential Delay (`src/App.Wpf/ViewModels/ServersViewModel.cs`)**:
   - Updated `JoinWithAccountAsync` `foreach` loop to also wait a randomized 60–120 seconds via `await Task.Delay(TimeSpan.FromSeconds(randomSeconds))` between accounts when multiple accounts are selected in the account picker.
3. **Launch Button Disabling (`src/App.Wpf/Views/Pages/AccountsPage.xaml`)**:
   - Bound `Accounts_LaunchButton` `IsEnabled` to `{Binding CanLaunchAccount}` and bound `Accounts_LaunchSelectedButton` and `Accounts_LaunchGroupButton` `IsEnabled` to `{Binding IsNotBusy}`.
4. **Unit Testing (`tests/App.Wpf.Tests/ViewModels/CheckAllPacingTests.cs`)**:
   - Added `ExecuteSequentialLaunchQueueAsync_RunsSequentiallyWith60To120SecondRandomizedDelay` verifying top-to-bottom launch order, `[60, 120]` inclusive random range requests, exact `TimeSpan.FromSeconds(randomSeconds)` delays between accounts, no trailing delay after the last account, and launch button disable/enable transitions.
