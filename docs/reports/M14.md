## 1. Scope & Implementation Summary

### App.Wpf Theme Contrast (`Tokens.xaml` & `ThemeTokens.cs`)
- **Tokens.xaml**:
  - Overrode default WPF-UI theme brushes for dark high contrast:
    - `ApplicationBackgroundBrush`: `#111111` (deep solid black background).
    - `CardBackgroundBrush` & `CardBackgroundFillColorDefaultBrush`: `#2D2D2D` (noticeably lighter gray to create visual card elevation).
    - `ControlFillColorDefaultBrush`: `#2D2D2D`.
    - `TextFillColorPrimaryBrush`: pure white `#FFFFFF` on dark backgrounds for maximum legibility.
    - `TextFillColorSecondaryBrush`: `#CCCCCC` for high readability on dark surfaces.
  - Redesigned Status Badge colors for high contrast and immediate readability:
    - `Valid`: vibrant forest green background (`#1B5E20`), crisp border (`#4CAF50`), pure white text (`#FFFFFF`).
    - `Expired` / `Error`: bright red background (`#B71C1C`), crisp border (`#EF5350`), pure white text (`#FFFFFF`).
    - `Unknown`: muted slate background (`#37474F`), crisp border (`#78909C`), pure white text (`#FFFFFF`).
    - `Running`: deep royal blue background (`#0D47A1`), crisp border (`#42A5F5`), pure white text (`#FFFFFF`).
  - Added DataGrid theme brushes:
    - `DataGridRowAlternatingBrush`: `#181818` (dark) / `#FAFAFA` (light).
    - `DataGridHeaderBorderBrush`: `#3E3E3E` (dark) / `#D0D0D0` (light).
  - Added `HighContrastColumnHeaderStyle` targeting `DataGridColumnHeader` with bold typography, distinct bottom border (`0,0,0,2`), and generous padding.
- **ThemeTokens.cs**:
  - Updated `ApplyTheme(ApplicationTheme theme)` to dynamically swap all contrast brushes (`ApplicationBackgroundBrush`, `CardBackgroundBrush`, `TextFillColorPrimaryBrush`, `TextFillColorSecondaryBrush`, `DataGridRowAlternatingBrush`, etc.) between Light and Dark modes.

### DataGrid Legibility (`AccountsPage.xaml`, `RunningPage.xaml`, `ServersPage.xaml`)
- Configured `AlternatingRowBackground="{DynamicResource DataGridRowAlternatingBrush}"` across all data tables.
- Applied `ColumnHeaderStyle="{StaticResource HighContrastColumnHeaderStyle}"` for bold column headers with distinct bottom dividing borders.
- Verified status badge templates render with sharp contrast against alternating row fills.

### WebView2 Placeholder (`LoginWindow.xaml`, `LoginWindow.xaml.cs`)
- Added `LoadingOverlay` containing a centered `ui:ProgressRing` and localized `TextBlock` `{x:Static resources:Strings.LoadingRoblox}` over `WebView2`.
- Attached to `CoreWebView2.NavigationCompleted`:
  - Automatically collapses `LoadingOverlay` once Roblox login page DOM finishes loading.
  - Automatically collapses overlay if initialization throws or aborts.
- Added localized string `LoadingRoblox` to both `Strings.resx` ("Loading Roblox...") and `Strings.vi.resx` ("Đang tải Roblox..."), with property in `Strings.cs`.

### Settings Page Polish (`SettingsPage.xaml`)
- Updated all 8 settings section cards with `Background="{DynamicResource CardBackgroundBrush}"` and `Margin="0,0,0,16"`.
- Verified all description and subtitle text binds to `TextFillColorSecondaryBrush` (`#CCCCCC`) for high legibility.
