## 4. Deviations & Blocked Items
- **Blocked: Multi-Instance Real Gate**:
  - Official Roblox documentation does not document or support a public named kernel object for multi-client execution. Under the project's Roblox Facts Policy and security boundaries, no speculative names were guessed or patched.
  - The functionality is abstracted behind `NamedMutexInstanceGate : IInstanceGate`. If no mutex name is provided, `IsAvailable` is false and the UI displays a localized "not available in this build" message.
  - The gate checks `IProcessProvider` (ensures zero Roblox processes running) before enabling, displays a risk warning dialog, requires explicit user acknowledgement, and immediately releases on disable/dispose.
