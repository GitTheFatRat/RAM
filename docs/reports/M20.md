# M20 Milestone Report: Zero-Cost Anti-Geo-Ban (Incognito Cookie Import)

## 1. Summary of Changes
- **Removed WebView2**:
  - Removed `Microsoft.Web.WebView2` package reference from `src/App.Wpf/App.Wpf.csproj` and `Directory.Packages.props`.
  - Deleted `LoginWindow.xaml` and `LoginWindow.xaml.cs`.
  - Updated `WindowsRegistryProvider.GetWebView2Version()` to query standard Windows EdgeUpdate registry keys directly without depending on the WebView2 SDK package.
- **Revamped Account Import (`AddAccountWindow` & `AddAccountViewModel`)**:
  - Created `AddAccountWindow.xaml` with a multi-line `ui:TextBox` (`AcceptsReturn="True"`) supporting one cookie per line or `User:Pass:Cookie` format.
  - Added localized anti-geo-ban banner (`Strings.AntiGeoBanHint`): *"Nếu không truy cập được Roblox Quốc tế, vui lòng sử dụng GoodbyeDPI hoặc WARP 1.1.1.1, sau đó mở trình duyệt ẩn danh để lấy Cookie."*
- **Native Incognito Browser Launcher (`IncognitoBrowserLauncher`)**:
  - Added "Mở Trình duyệt Ẩn danh (Lấy Cookie)" / "Open Incognito Browser (Get Cookie)" button.
  - Searches for Chrome (`--incognito`), Thorium (`--incognito`), Edge (`--inprivate`), and Brave (`--incognito`) in standard installation paths and `PATH`, with fallback to default system browser opening `https://www.roblox.com/login`.
- **Bulk Cookie Parsing & Processing (`BulkCookieParser`)**:
  - Parses multiple lines, extracts `.ROBLOSECURITY` tokens from raw lines, `User:Pass:Cookie`, or `.ROBLOSECURITY=...` headers, deduplicates, validates each via `IRobloxAuthService.ValidateCookieAsync`, and encrypts valid accounts into `IAccountStore`.
