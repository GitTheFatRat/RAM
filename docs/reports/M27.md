# Milestone Report — M27: Active Instance Tracking & Kill Switch

## Summary
- Added `[JsonIgnore] public int? ActiveProcessId { get; set; }` to `Account` (`src/Core/Models/Account.cs`).
- Updated `AccountItemViewModel` (`src/App.Wpf/ViewModels/AccountItemViewModel.cs`) with bindable `ActiveProcessId` and `IsRunning => ActiveProcessId.HasValue`, automatic process exit tracking (`Process.EnableRaisingEvents = true` / `Exited` handler resetting `ActiveProcessId = null` on UI thread when the Roblox window closes or crashes), and `KillInstanceCommand` (`Process.GetProcessById(ActiveProcessId.Value).Kill()`).

- Updated `AccountsPage.xaml` (`src/App.Wpf/Views/Pages/AccountsPage.xaml`) and localization resources (`Strings.cs`, `Strings.resx`, `Strings.vi.resx`) to display the `"Đang chạy"` (`"Running"`) indicator badge and `"Tắt"` (`"Kill"`) button bound to `IsRunning` and `KillInstanceCommand`.
