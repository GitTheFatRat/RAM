# M10: Master Password, Per-Account Proxy, and Background Resource Optimization (Target: v0.3.0)

Follow docs/prompts/RUNBOOK.md (rules, gates, token budget, security, autonomy). First add M10 to docs/STATE.md as pending. Batch file writes; do not narrate. The Reveal() allowlist must NOT grow beyond necessary Cryptography extensions.

## SCOPE
In: Master password defense-in-depth (Argon2id) for the live vault, per-account HTTP/SOCKS5 proxy configuration, and Win32-based background process resource optimization (FPS/Window throttling).
Out: Captcha bypass, auto-farm logic, script executors (strictly forbidden by SECURITY.md forever).

## CORE
1. `ProxyConfig` record: `string Host`, `int Port`, `string? Username`, `SecretValue? Password`, `ProxyType Type` (Http, Socks5).
2. `Account` record gains: `ProxyConfig? Proxy`. Update validation: Port must be 1-65535, Host must be valid URI/IP.
3. `IVaultKeyProvider`: Interface for providing the vault encryption key.
4. `MasterPasswordPolicy`: Domain logic enforcing minimum 12 characters if master password is enabled.

## INFRASTRUCTURE
5. **Vault Storage Security (Format v2)**:
   - Upgrade `EncryptedFileVault` to support Format v2.
   - Format v2 Binary Layout: `magic` ("RBXV"), `version` (0x02), `kdfType` (1 byte, 0 = DPAPI only, 1 = Argon2id + DPAPI).
   - If `kdfType == 1`: append `argonSalt` (16 bytes). The AES key is derived using Argon2id (Konscious.Security.Cryptography.Argon2 or NSec, verify net10.0 compatibility). The derived key is STILL wrapped via DPAPI CurrentUser for double-layer protection.
   - Fallback/Migration: Loading v1 (`version == 0x01`) still works. Saving upgrades to v2 automatically.
6. **Per-Account Proxy Routing**:
   - `RobloxHttpClientFactory`: Accept an optional `ProxyConfig`. If present, configure the `SocketsHttpHandler.Proxy` property with a `WebProxy`.
   - Ensure credentials in `ProxyConfig.Password` are decrypted only via `Reveal()` inside the `IHttpClientFactory` construction and zeroed immediately.
7. **Background Resource Optimization**:
   - `WindowController` (new): Use Win32 P/Invoke (`User32.dll`: `EnumWindows`, `GetWindowThreadProcessId`, `SetWindowPos`, `ShowWindow`).
   - Implement `ThrottleBackgroundProcesses()`: Find all Roblox processes not currently in the foreground. Send commands to minimize them or move them off-screen, reducing GPU/CPU rendering overhead for multi-instance farming.

## APP.WPF
8. **Master Password Flow**:
   - `App.xaml.cs` / Startup: Check `SettingsService`. If `IsMasterPasswordEnabled` is true, show a localized blocking `MasterPasswordWindow` before loading `MainWindow`. 
   - Incorrect password -> typed exception -> show "Invalid Password" (do not wipe the vault).
9. **Settings Page**:
   - Toggle: "Enable Master Password". If checked, open a dialog to set it (requires typing twice, strict validation).
   - Toggle: "Throttle background Roblox instances" (binds to a background timer calling `WindowController`).
10. **Account Editor**:
    - Add a "Proxy" tab in the account ContentDialog. Fields: Type (dropdown), Host, Port, Username, Password.
