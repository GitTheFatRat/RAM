# M30 FEATURE: Account Follower (Join via Username)

## PROBLEM
The user wants a secondary account (managed by the tool) to directly join the server of a primary account (currently playing) without needing them to be friends. The tool needs to take a target username, find their current Server ID (JobId), and launch the secondary account directly into that specific server.

## TASKS

1. **API Integration (User & Presence):**
   - **Resolve Username:** Add a method to call `https://users.roblox.com/v1/usernames/users` (POST) to get the `UserId` from the provided target username.
   - **Fetch Presence:** Add a method to call `https://presence.roblox.com/v1/presence/users` (POST) using a valid account cookie from the tool.
   - **Extract Data:** Parse the response to extract `placeId` and `gameId` (the Server Job ID).
   - **Error Handling:** If `gameId` is null, throw a clear exception (e.g., "Không tìm thấy máy chủ. Mục tiêu đang offline hoặc tắt quyền Joins").

2. **Update Launch Sequence:**
   - Modify the launch generator to accept an optional `JobId`.
   - When a `JobId` is provided, update the `PlaceLauncherUrl` query parameters:
     - Change `request=RequestGame` to `request=RequestGameJob`.
     - Append `&gameId={jobId}` to the URI.

3. **UI Integration:**
   - In the Launch/Servers tab, add a TextBox labeled "Theo đuôi (Tên người chơi)" (Target Username).
   - Update the ViewModel: When launching an account, if this TextBox has a value, pause the launch, execute the API calls to resolve the target's `placeId` and `gameId`, and then proceed with the specific server launch.
