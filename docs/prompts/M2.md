# M2: Roblox authentication, account add via login, validation, launch

Follow docs/prompts/RUNBOOK.md (rules, gates, token budget, security). This file only adds the M2 scope.

## SCOPE
In: HTTP layer for Roblox, add account via WebView2 login, cookie validation, game launch (place and specific server), security guard tests.
Out: server browser, process monitoring, auto-rejoin (M3), multi-instance, settings, backup (M4).

## CORE
1. RobloxUser record: long Id, string Name, string DisplayName.
2. Account gains: long? UserId, string? Username (exists), AccountStatus Status (Unknown, Valid, Expired, Error), DateTimeOffset? LastCheckedAt. Update validation and the vault DTO. The vault payload must stay backward compatible: loading a payload without the new fields works (tolerant defaults). File container version byte stays 1.
3. IRobloxAuthService:
   - Task<Result<RobloxUser>> ValidateCookieAsync(SecretValue cookie, CancellationToken ct)
   - Task<Result<SecretValue>> GetAuthTicketAsync(SecretValue cookie, CancellationToken ct)
   Result errors are typed codes (Expired, RateLimited, Network, Unexpected), never raw server text containing secrets.
4. LaunchRequest record: AccountId AccountId, long PlaceId, string? JobId. Validation: PlaceId > 0; JobId, when present, must be a GUID. (Private server code support: see "Private servers".)
5. ILauncher: Task<Result> LaunchAsync(LaunchRequest request, CancellationToken ct).

## INFRASTRUCTURE
6. RobloxHttpClient via HttpClientFactory, UseCookies = false (cookie goes only in an explicit per-request Cookie header, never in a shared container).
   - RobloxHostGuardHandler: if a request carries a Cookie header, it must be https and the host must be roblox.com or end with .roblox.com. Otherwise throw InvalidOperationException (message without the cookie).
   - CSRF: on 403 with an x-csrf-token response header, retry ONCE with that token in X-CSRF-TOKEN.
   - Polly: retry 429 and 5xx up to 3 times with exponential backoff plus jitter, honoring Retry-After. After exhausting retries return RateLimited / Network.
   - Ignore Set-Cookie responses (cookie rotation is a documented known limitation).
7. RobloxAuthService. HYPOTHESES to verify and record in docs/api-notes.md (mark UNVERIFIED when you cannot confirm):
   - Validate: GET https://users.roblox.com/v1/users/authenticated with the cookie. 200 returns id, name, displayName. 401 means Expired.
   - Ticket: POST https://auth.roblox.com/v1/authentication-ticket, empty JSON body, headers Referer https://www.roblox.com/ and X-CSRF-TOKEN (obtained via the 403 retry flow). The ticket is returned in the response header rbx-authentication-ticket.
8. RobloxLauncher : ILauncher.
   - Serialize launches with a SemaphoreSlim and enforce a minimum delay between launches (constant 3000 ms for now; M4 makes it a setting).
   - Check the roblox-player protocol handler exists (HKCU\Software\Classes\roblox-player\shell\open\command). If missing, return a localized "Roblox not installed" error.
   - Build the URI with a pure, unit-tested function. HYPOTHESIS: roblox-player:1+launchmode:play+gameinfo:{ticket}+launchtime:{unixMs}+placelauncherurl:{urlEncoded}+browsertrackerid:{trackerId}+robloxLocale:en_us+gameLocale:en_us+channel:+LaunchExp:InApp
     placelauncherurl HYPOTHESIS: https://assetgame.roblox.com/game/PlaceLauncher.ashx?request=RequestGame&browserTrackerId={trackerId}&placeId={placeId}&isPlayTogetherGame=false
     For a specific server: request=RequestGameJob and an added gameId={jobId}. Keep the host and format in one constant so the human can adjust them.
   - Start it with Process.Start(new ProcessStartInfo(uri) { UseShellExecute = true }). The URI contains the ticket: never log it, never store it.
   - Private servers: implement only if you can confirm the current format from public documentation. Otherwise mark "private server launch" BLOCKED in STATE.md and leave it out of the UI.
9. Atomicity: after validation, persist Username, UserId, Status, LastCheckedAt through IAccountStore.UpdateAsync.

## APP.WPF
10. LoginWindow (WebView2). The user types their own credentials on the real Roblox page; the app never sees the password.
    - Use a temporary user-data folder under %TEMP%\RbxManager\login-{guid}. Delete it recursively in a finally block (best effort).
    - Navigate to https://www.roblox.com/login. In NavigationStarting, cancel navigations to hosts that are not roblox.com or *.roblox.com.
    - Poll CoreWebView2.CookieManager for .ROBLOSECURITY on https://www.roblox.com once per second (timeout 10 minutes, or window closed = cancelled). When found, wrap it in SecretValue immediately and close the window.
    - If the WebView2 runtime is missing, show a localized error with a download hint. Do not crash.
11. Accounts page:
    - New buttons: "Add via login" (LoginWindow, then validate, alias defaults to the username and stays editable, uniqueness rules unchanged), "Add via cookie" (existing dialog), "Check" (selected account), "Check all", "Launch".
    - New columns: Username, Status (colored chip with text, not color alone), Last checked.
    - Check all: concurrency 3, cancellable, progress indicator.
    - Launch dialog: PlaceId (digits only, required), optional JobId (GUID). Remember the last PlaceId in memory only. Show localized errors for each Result code.
12. Handle Expired status: show a localized hint to re-add via login. Never delete the account automatically.
