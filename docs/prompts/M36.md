# M36 BUG FIX: Responsive UI & Window Minimum Resolution

## PROBLEM
When the main application window is resized to a smaller resolution, the DataGrid/ListView columns squash together. Text truncates improperly, and action buttons overlap because the window and columns lack minimum width constraints.

## TASKS

1. **Set Main Window Constraints:**
   - In `MainWindow.xaml` (or the shell view), add strict `MinWidth="900"` and `MinHeight="600"` properties to prevent the window from shrinking into an unusable state.

2. **Fix DataGrid/ListView Columns:**
   - In the Accounts view XAML, enforce `MinWidth` values on the columns (e.g., Name, Status, Actions) instead of relying purely on proportional `*` sizing.
   - Ensure the main list container has `ScrollViewer.HorizontalScrollBarVisibility="Auto"`. When the window hits its minimum width, the horizontal scrollbar should handle the rest, preventing columns from collapsing below their `MinWidth`.

3. **Fix Action Buttons Overlap:**
   - In the "THAO TÁC" column's `DataTemplate`, ensure the action buttons are wrapped in a `StackPanel` (Orientation="Horizontal") or `WrapPanel` with appropriate `Margin` or `Spacing`. Remove any negative margins that might be causing the visual overlap.

## FINISH
Run `dotnet build`.
