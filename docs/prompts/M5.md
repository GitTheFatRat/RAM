# M5: hardening, packaging, documentation, final audit

Follow docs/prompts/RUNBOOK.md (rules, gates, token budget, security). This file only adds the M5 scope.

## HARDENING
1. Global exception handling: DispatcherUnhandledException, TaskScheduler.UnobservedTaskException, AppDomain.UnhandledException. Log type and operation only (never message text that could carry secrets, never request URIs), show a localized error dialog, avoid crash loops.
2. App single-instance: a second launch of RbxManager focuses the first window and exits. Use a named mutex for the manager app itself (unrelated to Roblox).
3. Shutdown: stop hosted services, dispose the multi-instance gate, dispose SecretValue holders, flush logs.
4. Logging: Serilog file sink retains 14 days, Information level. Add a log redaction safety net: a Serilog enricher or destructuring policy that masks any string containing "_|WARNING:-DO-NOT-SHARE-THIS" or ".ROBLOSECURITY=" as "[REDACTED]". Unit test it.
5. Keyboard: Ctrl+F focuses search, Delete asks to delete the selected account, Enter on a selected account opens the launch dialog.

## QUALITY GUARDS (tests)
6. i18n parity test: every key in Strings.resx exists in Strings.vi.resx and vice versa, no empty values.
7. XAML literal test: scan src/App.Wpf/**/*.xaml and fail on literal user-visible text in Text= or Content= or Header= or Title= attributes that are not bindings or resource references. Allowlist the product name.
8. Secret scan test over tracked source and docs (not tests): fail if the strings "_|WARNING:-DO-NOT-SHARE-THIS" or ".ROBLOSECURITY=" followed by a long value appear outside tests.
9. Dependency report: run dotnet list package --vulnerable --include-transitive and dotnet list package --deprecated. Fix or document every finding in the final report.

## PACKAGING
10. tools/publish.ps1: dotnet publish src/App.Wpf -c Release -r win-x64, framework-dependent single-file into artifacts/, then zip as artifacts/RbxManager-win-x64.zip. A -SelfContained switch produces the self-contained variant. artifacts/ is gitignored.
11. CI (.github/workflows/build.yml): keep build and test; add a step that runs the publish script and uploads the zip as a workflow artifact. Do not publish releases automatically.
12. No installer and no code signing now.

## DOCUMENTATION

State clearly: personal use, not affiliated with Roblox, use at your own risk.
14. docs/MANUAL_TEST_CHECKLIST.md (Vietnamese). Step-by-step checks the HUMAN performs using a THROWAWAY Roblox account, never a main account, and never pasting a cookie anywhere except the app:
    - add via login, status becomes Valid, username shown
    - restart app, account persists; open vault.dat in Notepad, no readable alias or cookie
    - Check all, expired cookie handling (log out that session on roblox.com, then Check)
    - launch to a place, launch to a specific server from the server browser
    - Running page shows the session; Close; auto-rejoin by ending RobloxPlayerBeta in Task Manager; breaker after repeated kills
    - multi-instance with two throwaway accounts (only if the real gate is not BLOCKED)
    - backup export, wipe, import on a clean vault; wrong password message
    - corruption test: copy vault.dat, flip a byte in the copy, point a test run at it only if the app supports it, otherwise verify via automated tests and skip
    - search logs\ for "_|WARNING:-DO-NOT-SHARE-THIS" and expect no matches
    - one line per UNVERIFIED item from docs/api-notes.md describing what to observe
15. docs/BEFORE_PUBLIC_RELEASE.md: code signing, installer, antivirus false-positive plan, master password for the live vault, Roblox terms and trademark review of the name (RbxManager is a placeholder), license audit of all dependencies, privacy statement, third-party security review.
