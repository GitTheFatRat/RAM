# M21: GoodbyeDPI Automation Orchestrator

Follow docs/prompts/RUNBOOK.md. Batch file writes.

## PROBLEM
End-users find it difficult to manually find, download, and configure GoodbyeDPI to bypass ISP blocks in Vietnam. However, bundling the WinDivert driver inside the app triggers Anti-Cheat bans (Hyperion) and False-Positive AV flags. The application must act as a safe orchestrator to download and launch the tool externally.

## TASKS
1. **DpiToolService (The Orchestrator)**:
   - Create `src/Infrastructure/Network/DpiToolService.cs`.
   - **Check Status**: Method to check if a process named `goodbyedpi` is currently running.
   - **Download & Extract**: If the tool does not exist in `%LOCALAPPDATA%\RbxManager\Tools\GoodbyeDPI`, download the stable release ZIP (e.g., v0.2.3 from `https://github.com/ValdikSS/GoodbyeDPI/releases/download/0.2.3/goodbyedpi-0.2.3.zip`). Extract it to the Tools folder.
   - **Launch**: Execute the `1_russia_blacklist.cmd` (or equivalent standard cmd) using `ProcessStartInfo` with `UseShellExecute = true` and `Verb = "runas"` to ensure it requests Administrator privileges via standard UAC.
2. **UI Integration (`AddAccountWindow.xaml`)**:
   - Replace the static instruction text from M20 with a dynamic status area.
   - Add a prominent Button: "Cài đặt & Bật GoodbyeDPI" (Install & Start GoodbyeDPI).
   - Bind this button to a command in `AddAccountViewModel`. 
   - Once running, disable the button and change the text to "✅ GoodbyeDPI đang hoạt động" (GoodbyeDPI is running).
3. **UX Polish**:
   - Display an indeterminate ProgressBar or ProgressRing while the ZIP is downloading.
   - Show a localized error Snackbar if the user denies the UAC (Admin) prompt or if the network blocks the GitHub download.

## FINISH
Run `dotnet build -c Release`.
Commit "feat: M21 orchestrator to auto-download and launch GoodbyeDPI safely".
