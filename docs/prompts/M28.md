# M28 FEATURE: Force Custom Window Resolution via Win32 API

## PROBLEM
For multi-account farming, running Roblox at native resolution consumes too much GPU/CPU. Users need a way to force every newly launched Roblox instance to a specific custom resolution (e.g., 800x600) automatically to save resources. Modifying Roblox XML config files is unreliable for multi-instance, so dynamic resizing via Win32 API is required.

## TASKS

1. **Configuration & UI:**
   - In `AppSettings.cs`, add `bool EnableCustomResolution`, `int ResolutionWidth = 800`, and `int ResolutionHeight = 600`.
   - In `SettingsPage.xaml` (and `SettingsViewModel`), add UI controls to toggle this feature and input the Width/Height.

2. **Win32 API P/Invoke (`src/Infrastructure/Native/User32.cs` or similar):**
   - Import the `SetWindowPos` function from `user32.dll`:
     `[DllImport("user32.dll", SetLastError = true)]`
     `public static extern bool SetWindowPos(IntPtr hWnd, IntPtr hWndInsertAfter, int X, int Y, int cx, int cy, uint uFlags);`
   - Define constants: `SWP_NOMOVE = 0x0002`, `SWP_NOZORDER = 0x0004`.

3. **Window Resizing Logic:**
   - Hook into the launch workflow right after the Process ID is captured (built in M27).
   - Once the process is launched, create a polling loop (e.g., max 10 seconds, checking every 500ms) to wait until `Process.MainWindowHandle` is no longer `IntPtr.Zero`.
   - Once `MainWindowHandle` is available, if `EnableCustomResolution` is true, execute `SetWindowPos(process.MainWindowHandle, IntPtr.Zero, 0, 0, width, height, SWP_NOMOVE | SWP_NOZORDER);`.
