# M20: Zero-Cost Anti-Geo-Ban (Incognito Cookie Import)

Follow docs/prompts/RUNBOOK.md. Batch file writes.

## PROBLEM
The current WebView2 implementation is useless for users in restricted regions (like Vietnam) because the default network routes to a censored or locked domain (e.g., VNG portal). Implementing a complex internal Proxy is overkill for free users. We need a lightweight, robust bulk-cookie import feature coupled with a native incognito browser launcher so users can fetch cookies externally using tools like GoodbyeDPI or WARP.

## TASKS
1. **Remove WebView2**:
   - Completely remove the WebView2 control and its references from `LoginWindow.xaml` and the project.
2. **Revamp `LoginWindow.xaml` (Bulk Cookie Import)**:
   - Rename to `AddAccountWindow.xaml` (update ViewModels accordingly).
   - The primary UI must be a large `TextBox` (AcceptsReturn="True") allowing users to paste multiple cookies (one per line, or `User:Pass:Cookie` format).
   - Add an informational localized text block explaining: "Nếu không truy cập được Roblox Quốc tế, vui lòng sử dụng GoodbyeDPI hoặc WARP 1.1.1.1, sau đó mở trình duyệt ẩn danh để lấy Cookie." (If you cannot access Global Roblox, use GoodbyeDPI/WARP, then open an incognito browser to get the Cookie).
3. **Native Incognito Launcher**:
   - Add a prominent button: "Mở Trình duyệt Ẩn danh (Lấy Cookie)" / "Open Incognito Browser (Get Cookie)".
   - When clicked, execute a command to open the user's default browser (or specifically Chrome/Edge/Thorium if found) in incognito/private mode navigating to `https://www.roblox.com/login`.
   - *Implementation detail:* Use `Process.Start` with arguments like `chrome.exe --incognito https://www.roblox.com/login`. Provide fallbacks if Chrome is not in PATH.
4. **Processing Logic**:
   - Add an "Import Accounts" button.
   - When clicked, parse the text box, extract valid `.ROBLOSECURITY` cookies, and process them through the existing `RobloxAuthService` using the default network (which is now expected to be unblocked by the user's external DPI tool).
   - Encrypt and store successful accounts into the Vault.

## FINISH
Run `dotnet build -c Release`.
Commit "feat: M20 replace WebView2 with bulk cookie import and native incognito launcher".
