M29 FEATURE: UI Text & Language Simplification

PROBLEM

The current UI text (especially in SettingsPage.xaml) is too verbose and exposes too much internal technical logic to the end-user (e.g., mentioning "Argon2id", "Windows DPAPI", "Win32 API", etc.). The user wants a clean, consumer-facing UI where descriptions are extremely concise (ideally 1 to 4 words maximum) and easy to understand without technical jargon.

TASKS

Audit XAML Files: Open SettingsPage.xaml (and any other pages with long descriptions).

Rewrite Labels and Descriptions: Replace all lengthy descriptions with short, punchy Vietnamese phrases (1-4 words).

Suggested Replacements (Apply these and similar simplifications):

Mật khẩu chính (Argon2id, DPAPI...) -> "Bảo vệ dữ liệu" (Protect data) or "Khóa ứng dụng" (Lock app).

Tối ưu tài nguyên Roblox chạy nền (Thu nhỏ cửa sổ...) -> "Giảm tải CPU/GPU" (Reduce CPU/GPU).

Bật tối ưu RAM tự động (Định kỳ giải phóng...) -> "Tối ưu RAM ngầm" (Optimize background RAM) or "Tự động dọn RAM" (Auto-clean RAM).

Chu kỳ giải phóng RAM (Tần suất tối ưu hóa...) -> "Thời gian dọn dẹp" (Clean interval).

Ép độ phân giải cửa sổ tùy chỉnh (Tự động thu nhỏ qua Win32 API...) -> "Ép độ phân giải" (Force resolution).

Ghi lại chi tiết luồng thực thi... ra tệp... -> "Xuất log ra Desktop" (Export log to Desktop).

Nâng cao (Tùy biến mẫu URI...) -> "Cấu hình hệ thống" (System config).

Remove Technical Jargon: Ensure absolutely NO technical terms (Win32, API, Argon2id, DPAPI, JSON, FFlag) are visible in the user-facing text.
