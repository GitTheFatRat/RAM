# M11: Smart RAM Cleaner (Background Memory Optimization)

Follow docs/prompts/RUNBOOK.md (rules, gates, token budget, security, autonomy). First add M11 to docs/STATE.md as pending. Batch file writes; do not narrate.

## SCOPE
In: A background service that periodically forces Windows to trim the working set of all running Roblox processes tracked by the application, significantly reducing RAM usage over long sessions.
Out: Modifying or inspecting process memory directly, process injection.

## CORE
1. `AppSettings` gains: `bool EnableRamCleaner` (default: false), `int RamCleanerIntervalMinutes` (default: 15, min: 5, max: 120). Update `ISettingsService` and validation logic.
2. `IMemoryOptimizer`: New interface with a single method `Task TrimMemoryAsync(CancellationToken ct)`.

## INFRASTRUCTURE
3. `WindowsMemoryOptimizer` implementing `IMemoryOptimizer`:
   - Use P/Invoke to call `kernel32.dll` -> `SetProcessWorkingSetSize(IntPtr hProcess, int dwMinimumWorkingSetSize, int dwMaximumWorkingSetSize)`.
   - Pass `-1` for both sizes to explicitly command the OS to swap out idle memory pages for the target process.
   - Inject `IProcessProvider` to get all current Roblox process IDs (`ProcessSnapshot`).
   - Iterate through tracked Roblox processes. Open the process handle with `PROCESS_SET_QUOTA` (0x0100) and `PROCESS_QUERY_INFORMATION` (0x0400), apply the working set size, and explicitly close the handle via `SafeProcessHandle` or `CloseHandle`.
   - Catch and gracefully ignore Access Denied errors (some processes might be elevated or closing).
4. `RamCleanerService`: A `BackgroundService` (IHostedService) that checks `AppSettings.EnableRamCleaner`.
   - If enabled, it waits for `RamCleanerIntervalMinutes`, calls `IMemoryOptimizer.TrimMemoryAsync()`, and loops.
   - Logs the number of processes trimmed (operation counts only).
