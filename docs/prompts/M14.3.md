# M14.3 HOTFIX: Deep UI/UX Polish & DataGrid Restyling

Follow docs/prompts/RUNBOOK.md (rules, gates, token budget). Batch file writes.

## PROBLEM
The UI contrast remains extremely poor after M14. Specifically:
1. The DataGrid rows have glaring white backgrounds in Dark mode, breaking the theme.
2. The overall application background and control backgrounds are too similar, lacking elevation and contrast. 
The standard `WPF-UI` resource overrides in `Tokens.xaml` were likely insufficient or overwritten.

## TASKS
1. **Fix DataGrid White Row Backgrounds**:
   - In `src/App.Wpf/Views/Pages/AccountsPage.xaml` and `RunningPage.xaml`, explicitly define the `RowStyle` for the `DataGrid`.
   - Ensure the `DataGridRow` `Background` is bound to the correct `WPF-UI` dynamic resource for dark theme (e.g., `{DynamicResource ControlFillColorDefaultBrush}`).
   - Ensure `AlternatingRowBackground` uses a slightly different dark brush (e.g., `{DynamicResource ControlFillColorSecondaryBrush}`). 
   - **Crucial:** Ensure the `Foreground` (text color) is explicitly set to `{DynamicResource TextFillColorPrimaryBrush}` so text remains visible against the dark rows.
2. **Force Application Contrast**:
   - In `MainWindow.xaml`, ensure the `ui:WindowBackground` or the main grid background is explicitly set to a very dark brush, like `{DynamicResource ApplicationBackgroundBrush}` or a hardcoded dark hex (e.g., `#1A1A1A`) if the dynamic resource fails.
   - Wrap the main content area (where the DataGrid sits) inside a `ui:CardControl` or give it a distinct background (`#2B2B2B`) with a `CornerRadius` and `Margin` to separate it from the main window background.
3. **Column Header Polish**:
   - Apply a custom `ColumnHeaderStyle` to the DataGrid. Make the headers bold, uppercase, with a distinct bottom border (`BorderThickness="0,0,0,1"`, `BorderBrush="{DynamicResource DividerStrokeColorDefaultBrush}"`).
