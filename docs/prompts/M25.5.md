# M25.5 BUG FIX: Persistent Place ID

## PROBLEM
The user inputs a "Place ID" (e.g., Roblox Game ID) into the UI, but the value is lost whenever they navigate away from the page or restart the application. The value is not being persistently saved or loaded.

## TASKS
1. **Locate the Target Property:** Find the ViewModel responsible for the Place ID input (likely `ServersViewModel` or `SettingsViewModel`).
2. **Bind to Persistent Storage:** 
   - Ensure the `PlaceId` string/number property is connected to the application's persistent configuration system (e.g., `appsettings.json`, `Properties.Settings.Default`, or your custom `AppSettings` class).
   - Update the property's `set` accessor so that whenever the user pastes a new ID, it immediately saves that value to the persistent storage file.
3. **Load on Initialization:** Update the ViewModel's constructor (or the App startup logic) to read the saved `PlaceId` from the configuration file and populate the UI property automatically.
