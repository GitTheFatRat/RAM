## SETTINGS
1. AppSettings (non-secret): Language (vi|en, default vi), Theme (System|Dark|Light, default Dark), LaunchDelayMs (min 1000, default 3000), RejoinDelaySeconds (default 10), RejoinMaxAttempts (default 5), MultiInstanceEnabled (default false), MultiInstanceAcknowledged (default false).

4. Settings page UI with all of the above. No secrets ever appear in settings.

Persist MultiInstanceAcknowledged only after explicit acceptance. Default stays OFF.

## GROUPS AND BULK LAUNCH
9. Accounts page: group filter chips built from existing groups (plus "All"), editable group combo box in the Add/Edit dialog, "Rename group" (bulk update with duplicate-safe handling).
10. Multi-select in the account grid. "Launch selected" and "Launch group": ask PlaceId (and optional JobId) once, launch sequentially using LaunchDelayMs, cancellable, per-account result list. If multi-instance is off and Roblox is running, the M3 launcher error applies.

## ENCRYPTED BACKUP
11. Export to a .rbxbackup file chosen with a SaveFileDialog. Password entered twice, minimum 12 characters, never stored or logged, buffers zeroed after use. Disabled when the vault is empty.
12. Format v1: magic "RBXB" (4) | version byte 1 | salt (16) | iterations (UInt32 LE) | nonce (12) | tag (16) | ciphertext. Key = PBKDF2-HMAC-SHA512 via Rfc2898DeriveBytes.Pbkdf2, 32-byte key, iterations at least 600000, fresh random salt and nonce per export. AES-GCM with explicit 16-byte tag. AAD = magic + version + salt + iterations. Plaintext is the serialized account list, including cookies, never written unencrypted anywhere.
13. Import: OpenFileDialog, password. Reject iterations below the minimum (downgrade protection) and unknown magic or version. Wrong password or tampering both raise one typed BackupException with a generic message that does not reveal which one. Merge policy: skip accounts whose alias already exists (case-insensitive); show a summary (imported, skipped). Never overwrite existing accounts.
14. SecretValue.Reveal() allowlist in ArchitectureTests gains the backup serializer (justify in the report).
