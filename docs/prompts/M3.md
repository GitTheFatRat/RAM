# M3: server browser, process monitor, running sessions, auto-rejoin

Follow docs/prompts/RUNBOOK.md (rules, gates, token budget, security). This file only adds the M3 scope.

## SCOPE
In: public server browser, Roblox process monitoring mapped to accounts, Running page, close actions, auto-rejoin.
Out: multi-instance unlocking, settings UI, backup (M4). Disconnect detection beyond process exit is out of scope.

## CORE
1. ServerInfo record: string Id, int Playing, int MaxPlayers, double? Fps, int? Ping.
2. IServerBrowserService: Task<Result<ServerPage>> GetServersAsync(long placeId, ServerSort sort, string? cursor, CancellationToken ct). ServerPage: IReadOnlyList<ServerInfo> Servers, string? NextCursor. ServerSort: Ascending, Descending (by player count).
3. RunningSession record: AccountId AccountId, LaunchRequest Request, int ProcessId, DateTimeOffset StartedAt.
4. IProcessProvider (abstraction for tests): IReadOnlyList<ProcessSnapshot> GetRobloxProcesses() where ProcessSnapshot holds Pid, StartTime, WorkingSetBytes. Kill(pid, graceful).
5. IInstanceGate: bool IsMultiInstanceEnabled { get; }. Implement now as a trivial class returning false; M4 replaces it.
6. RejoinPolicy (pure logic, uses TimeProvider): decides whether and when to relaunch after an unexpected exit. Defaults: delay 10 s, doubling backoff, maximum 5 attempts inside a rolling 30 minute window (circuit breaker). After the breaker trips, stop and report "gave up". An intentional close never triggers a rejoin.

## INFRASTRUCTURE
7. ServerBrowserService. HYPOTHESIS to verify and record in docs/api-notes.md: GET https://games.roblox.com/v1/games/{placeId}/servers/Public?sortOrder=Asc|Desc&limit=100&cursor={cursor}, no cookie needed. The response has data[] items with id, playing, maxPlayers, fps, ping and a nextPageCursor. Reuse the M2 Polly policy for 429.
   You MAY perform exactly ONE live unauthenticated GET of this endpoint, using any public place id you can find in public Roblox documentation or a public game URL, only to confirm the real JSON shape. Record the observed shape. If the request fails, mark the endpoint UNVERIFIED and continue. Never send a cookie.
8. SystemProcessProvider: Process.GetProcessesByName("RobloxPlayerBeta"), tolerant of access and race errors. Kill: CloseMainWindow, wait 5 s, then Kill.
9. SessionTracker (hosted background service):
   - Poll every 2 seconds. Detect new and exited Roblox processes.
   - Mapping: launches are already serialized by RobloxLauncher. After a launch for account A, take a baseline of PIDs before launching, then wait up to 60 s for exactly one new PID and bind it to A. If none or more than one appears, leave it unbound and log a warning (operation name and counts only).
   - Raise events SessionStarted, SessionEnded (with an "intentional" flag set only when the app itself closed it).
   - Auto-rejoin: per-account toggle (in memory in M3; M4 persists defaults). On unexpected end and toggle on: consult RejoinPolicy, wait the delay, then call ILauncher with the same LaunchRequest. Before relaunch, re-validate the cookie through IRobloxAuthService; if Expired, stop rejoining, set Status Expired, show a snackbar.
10. Update RobloxLauncher: if any Roblox process is running and IInstanceGate.IsMultiInstanceEnabled is false, return a localized error "Roblox is already running; enable multi-instance in Settings" instead of launching.
