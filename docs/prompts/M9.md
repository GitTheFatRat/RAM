## 3. REDACTION FIX (production code was fitted to tests)
Findings: DiagnosticsService.SanitizeReport contains the literals FAKE_COOKIE_ and FAKE_TICKET_, which makes its tests pass by construction. Its pattern also stops at the "|" character, so a cookie of the real shape (warning prefix, then ".|_", then a long token) keeps its secret tail unredacted. Verified: `_|WARNING:-DO-NOT-SHARE-THIS.--...items.|_TAILTOKEN` becomes `[REDACTED]|_TAILTOKEN`.
1. Remove every FAKE_ literal from production code.
2. Redact with patterns that cover the whole token: `_\|WARNING:-DO-NOT-SHARE-THIS\S*`, `\.ROBLOSECURITY=\S*`, and a standalone tail pattern `\|_[A-Za-z0-9]{16,}`.
3. Mask the Windows user name in any printed path (C:\Users\<name>\... becomes C:\Users\<user>\...), including ProtocolHandlerCommand.
4. RobloxSecretRedactionEnricher: also handle StructureValue, SequenceValue and DictionaryValue recursively, not only scalar strings.
5. Tests must use a realistic-shaped fake cookie: "_|WARNING:-DO-NOT-SHARE-THIS.--Sharing-this-will-allow-someone-to-log-in-as-you-and-to-steal-your-ROBUX-and-items.|_FAKE0123456789ABCDEFSECRETTAIL" and assert that neither the prefix nor the tail survives in the diagnostics report, in log output and in redacted structured properties. Existing log-leak tests also switch to this shape.

## 5. COOKIE MEMORY HYGIENE
Finding: every vault operation and every launch decrypts ALL accounts into SecretValue objects that are never disposed (only the finalizer zeroes them), which widens the exposure window.
1. EncryptedFileVault Add, Update and Remove: after the save completes, dispose every loaded account's cookie EXCEPT the instance passed in by the caller (the caller owns it).
2. RobloxLauncher and DiagnosticsService paths that call ListAsync: dispose the cookies of all loaded accounts in a finally block once the needed work is done.
3. Tests with a fake store: after launch, every loaded cookie is disposed (Reveal throws ObjectDisposedException); the caller-owned instance passed to AddAsync stays usable.
