# M25.1 BUG FIX: Json Serialization crashes in Trimmed Build

## PROBLEM
When running the published executable (which uses `<PublishTrimmed>true`), the app crashes on startup with the error: "Reflection-based serialization has been disabled for this application. Either use the source generator APIs or explicitly configure the 'JsonSerializerOptions.TypeInfoResolver' property."
This is because `System.Text.Json` relies on reflection, which is stripped during trimming.

## TASKS
1. Locate all data models used for JSON serialization (e.g., AppSettings, Account models, etc.).
2. Create a partial class inheriting from `JsonSerializerContext`.
3. Decorate it with `[JsonSerializable(typeof(YourModel))]` for every model that gets serialized/deserialized.
4. Update the `JsonSerializer.Serialize` and `Deserialize` calls in the codebase to pass the new `Context.Default.YourModel` type info resolver instead of relying on reflection.
5. Ensure the app works correctly when compiled with `-p:PublishTrimmed=true`.
