# M18: Live Integration Test Suite (No Mocks)

Follow docs/prompts/RUNBOOK.md. Batch file writes.

## PROBLEM
The user requires absolute proof that the application correctly interacts with real Roblox infrastructure (Live APIs, real endpoints, real HTML parsing), independent of the mocked unit/UI tests from M15 and M16.

## TASKS
1. **Create Live Test Project**:
   - Create `tests/Infrastructure.LiveTests/` (net10.0-windows, xunit).
   - This project MUST NOT reference any fakes or mocks. It uses the real `RobloxHttpClientFactory`, `RobloxAuthService`, and `ServerBrowserService`.
2. **Environment Guard (Safety First)**:
   - Live tests must be explicitly opted-in to prevent CI bans. 
   - Read environment variable `RBX_LIVE_TEST_COOKIE`. If it is null or empty, `Assert.Skip("Live testing disabled. Set RBX_LIVE_TEST_COOKIE to run.")` (or equivalent xUnit skipped behavior) for all tests in this project.
3. **Live API Tests (Read-Only)**:
   - Write a test that takes `RBX_LIVE_TEST_COOKIE`, validates it via `RobloxAuthService`, and successfully retrieves the real `RobloxUser` (Username, UserId). Assert that the ID > 0.
   - Write a test for `ServerBrowserService.GetServersAsync`. Hit a highly active public PlaceId (e.g., Blox Fruits: 2753915549). Assert that the returned `ServerPage` contains actual servers with non-empty `JobId`s and valid player counts.
4. **Integration**:
   - Add the project to the solution. Do not include it in the default `dotnet test` run in `verify-clean-clone.ps1` to prevent local dev failures. Create a script `tools/run-live-tests.ps1` that takes a cookie parameter and runs this specific suite.

## FINISH
Run `dotnet build -c Release`.
Commit "test: M18 live integration suite against real Roblox endpoints".
