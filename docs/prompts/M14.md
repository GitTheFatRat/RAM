## APP.WPF
1. **Theme Contrast (Tokens.xaml & ThemeTokens.cs)**:
   - The current Dark theme is too flat. Override the default `wpf-ui` brush dictionaries to increase contrast.
   - Set `ApplicationBackgroundBrush` to a deeper black (e.g., `#111111` or `#000000`).
   - Set `CardBackgroundBrush` and `ControlFillColorDefaultBrush` to a noticeably lighter gray (e.g., `#2D2D2D`) to create "elevation".
   - Ensure text brushes (`TextFillColorPrimaryBrush`) use pure white (`#FFFFFF`) for maximum legibility on dark backgrounds.
2. **DataGrid Legibility (`AccountsPage.xaml`, `RunningPage.xaml`)**:
   - Add alternating row backgrounds (`AlternatingRowBackground`) using a subtle highlight brush.
   - Bold the DataGrid column headers and give them a distinct bottom border.
   - Ensure the "Status" chips (Valid, Expired) use highly contrasting background colors (e.g., bright green for Valid, bright red for Expired).
3. **WebView2 Placeholder (`LoginWindow.xaml` / `AccountEditorControl`)**:
   - The WebView2 control currently appears as a void before navigation completes.
   - Add a "Loading Roblox..." overlay (a `Grid` with a localized `TextBlock` and a `ui:ProgressRing`) that sits behind or on top of the WebView2. Hide this overlay in the `NavigationCompleted` event.
4. **Settings Page Polish (`SettingsPage.xaml`)**:
   - Add `Margin="0,0,0,16"` to all `ui:CardControl` elements to properly separate the settings sections.
   - Ensure the description text below setting titles uses a lighter gray (`TextFillColorSecondaryBrush`), not dark gray.
