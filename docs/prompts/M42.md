Context: Using CDP or automation browsers for Roblox login/signup triggers Arkose Labs FunCaptcha and session locks. We need a 100% native, undetectable cookie ingestion flow.

Task: Build a "Local Extension Bridge" for seamless 1-click account importing from a regular Chrome/Edge/Brave browser.
1. Create a new folder `tools/BrowserExtension/` containing a Manifest V3 Chrome Extension (`manifest.json`, `background.js`, `popup.html`, `popup.js`).
2. The extension must have permissions for `cookies` and host permissions for `*://*.roblox.com/*` and `http://127.0.0.1/*`.
3. In `RbxManager` (`src/Infrastructure` & `src/App.Wpf`), implement a lightweight loopback `HttpListener` bound strictly to `http://127.0.0.1:48123/import` that listens only while `AddAccountWindow` is open (or via a toggle).
4. When the user logs into or registers an account on `roblox.com` in their normal browser and clicks the Extension button:
   - The extension reads the `.ROBLOSECURITY` cookie via `chrome.cookies.get`.
   - It sends a POST request with the cookie to `http://127.0.0.1:48123/import`.
   - Once RbxManager returns HTTP 200 OK (validating and saving the account to the vault), the extension MUST immediately call `chrome.cookies.remove` ONLY on `.ROBLOSECURITY` (preserving all other anti-bot/session cookies) and redirect the tab to `https://www.roblox.com/login` so the user is instantly ready for the next account without invalidating the captured token.
5. Ensure strict security: never log the raw cookie, and validate `Origin` headers on the loopback listener.
